---
name: module-creation
description: Guía para crear un nuevo módulo en la arquitectura del proyecto.
---

- Cuando el proyecto requiere un nuevo módulo, se debe seguir la arquitectura propuesta en el archivo `ARCHITECTURE.md` (ubicado en la raíz del proyecto) para garantizar consistencia y adherencia a la arquitectura establecida.
- Crea archivos `.gitkeep` en cada subcarpeta, del módulo, para asegurar que Git rastree la estructura de carpetas vacías.
